Your boards, your runs

This is a rig's own dashboard: its boards, the runs on them, the firmware it holds and how the host is set up. It works on its own, and it can be connected to a farm portal from Settings.

Connect with the rig's key

The key is on the rig: sudo cat /etc/alteriom-hil/api-token. It remains in this browser tab only.
